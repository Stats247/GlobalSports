Required backend API contract

Deploy a Google Apps Script web app connected to your spreadsheet. The endpoint should support listUsers, createUser, setUserStatus, getAuthSettings, setAuthSettings, signup, and login. It must validate administrator identity for admin actions, hash passwords with a suitable identity provider (never store raw passwords in Sheets), enforce login/signup switches server-side, rate-limit sign-in attempts, and return JSON. Use a separate predictions sheet and ai_prediction_history sheet for prediction records and AI analysis history; persist timestamps, source/model, match, prediction, confidence, final result, and outcome. All read/write actions must authorize the current user and restrict private data appropriately. Suggested users sheet columns: userId, fullName, email, role, active, createdAt, updatedAt.
